# Canaã Telecom — Landing Page

Site estático em HTML, CSS e JavaScript, pronto para GitHub e Vercel.

## Publicar

1. Extraia este ZIP.
2. Crie um repositório no GitHub e envie os arquivos e a pasta logos para a raiz do repositório.
3. Na Vercel, importe o repositório.
4. Selecione o preset Other. Deixe Build Command vazio e use a raiz como Output Directory (.).
5. Publique.

Não precisa instalar dependências nem configurar variáveis de ambiente.

## Editar

- index.html: textos, planos e estrutura.
- style.css: cores, layout e responsividade.
- app.js: carrosséis, pop-up de contato e mensagens do WhatsApp.
- logos/: logos dos serviços.
